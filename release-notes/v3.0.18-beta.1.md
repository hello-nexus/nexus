## Highlights

- **Updated OpenRGB with new devices.** Adds ASRock RX 9070 XT Steel Legend Dark, Gigabyte RTX 5090 XTREME WATERFORCE WB, Gigabyte RTX 4070 SUPER Eagle OC ICE, KFA2 RTX 4080 SG 1-Click OC, Corsair K60 RGB PRO SE, Corsair Sabre RGB Optical, Razer Naga Pro V3 (wired and wireless), the Cooler Master GM34-CWQ monitor and more MSI Mystic Light boards. More versions of the Sapphire RX 9070 XT Nitro+, PNY RTX 5070 Ti Epic-X and Zotac RTX 4070 Ti Trinity are also recognized.
- **Large performance gains.**
  - A minimized Nexus window uses almost no CPU (about 6% of a core down to under 1% in our tests) and gives back its memory.
  - Panel screens draw animated backgrounds only as fast as the panel can show them, not at your main monitor's refresh rate.
  - Streamed LCD panels use less CPU, and a memory leak on them is fixed.
  - The Lighting page stays light while effects are running.
  - Nexus opens faster, and the Monitoring page shows data right away.
  - Lower memory use on CPUs with large caches.
- **New monitoring layouts.** Wide and large monitoring widgets can show big gauges over a row of small readings ("2 large + 3 small" and "4 large + 3 small"). Bar layouts can show a different device on each row with "Multiple devices", and the full-screen view now shows every monitoring graph on the page at once.
- **Lian Li animations across every fan.** Runway, Tide, Mixing and Stack can travel through a whole Uni Hub SL-Infinity with "Merge all ports". Runway and Tide can do the same across a wireless SL V3 chain with "Merge all fans".
- **Static panel backgrounds in Focus mode.** A new per-mode option shows a plain background instead of an animated one on panels like the Y70 while a focus mode is on.

## Also in this release

- The benchmark leaderboard lets you browse the whole board instead of only the top 50.
- Benchmark results go to the leaderboard automatically only when "Help improve Nexus" is on. When it's off, you can upload a run yourself from your history.
- Nexus reopens in fullscreen if you closed it in fullscreen.

## Fixes

- The widget list on a panel's Widgets tab scrolls instead of cutting off.
- Tryx Panorama: the media library now lists everything on the panel, including videos and themes added from Tryx's own app, with thumbnails.
- Widgets keep their state while you drag or edit them: Twitch chat, album art and running timers no longer reset.
- The tray icon comes back on its own if Nexus's helper stops unexpectedly.
- macOS: "Open" in the menu bar goes straight to the page you left, without flashing the home page first.
- Turning off "Remember last page" now clears the saved page.
- OpenRGB: Corsair K100 lighting is more reliable, the HyperX QuadCast 2 S and Gigabyte RTX 5090 XTREME WATERFORCE layouts are corrected, and Intel GPUs and RGB memory are detected more reliably.
- Linux: RGB memory and motherboard lighting can work on AM5 boards (setup offers the kernel option they need), the service starts at boot again after an upgrade, panel screens work on X11 desktops, and settings stay in one place.
